A simple website to draw images and export them in a format compatible with Microbit's 5x5 led display
You can test the code at [https://python.microbit.org/v/3/](url) using the simulator or by flashing directly to a Microbit.
You can save frames and export them with sleep lines of a desired length to create easy animations.

Plans: 
1) Add mobile version
2) Add ways to insert or delete frames
3) Move JavaScript and Css into separate files
